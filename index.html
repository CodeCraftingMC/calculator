CalcFlex

What is CalcFlex?

Calcflex is a free Desktop Calculator designed to be as versatile and user-friendly as possible. It can do basic functions like addition and subtraction very easily, but can also be used to calculate more complex functions just as easily. CalcFlex runs on C# and WinForms

CalcFlex functions

All of the following functions are implented in CalcFlex:

  • basic operators including addition, subtraction, multiplication, division, exponentiation
  • bracket parsing
  • sqrt, root, log2, log10, log, ln, exp
  • all trigonemtry functions (inverse and hyperbolic included)
  • other functions including abs, mod and fact

CalcFlex version

Work on CalcFlex 2.0 has started, which will be developed in C++ and SFML and have way more features. But for now CalcFlex 1.0 is the latest version.
